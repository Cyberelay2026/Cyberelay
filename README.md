# Cyberelay V1

First working public-facing milestone for Cyberelay.ca.

## Included
- Responsive homepage
- Browse computers page
- Search + brand/RAM/storage filters
- Individual computer detail pages
- Facebook Marketplace outbound CTA
- Three seed laptop listings
- Placeholder Sell and About pages
- Data model shaped for later Supabase migration

## Run locally
```bash
npm install
npm run dev
```
Then open http://localhost:3000
